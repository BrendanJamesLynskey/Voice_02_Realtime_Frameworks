# Voice 02 — Real-Time Frameworks

A deep-dive presentation covering the orchestration layer for production voice agents: why a real-time framework is needed, the Pipecat pipeline and processor model, LiveKit Agents built on WebRTC, the OpenAI Realtime API speech-to-speech architecture, gpt-4o native audio with no STT/TTS hop, Gemini Live and Claude Voice, Twilio and SIP telephony bridges, and a practical stack-selection guide.
